# Contribuir a ScanMac

Abre un issue que describa el problema, la versión de macOS, el tipo de Mac y cómo reproducirlo con un documento sintético. No publiques documentos privados, nombres de familiares, contraseñas, tokens, índices de biblioteca ni rutas personales.

Para una mejora, explica el comportamiento esperado y envía una pull request con cambios pequeños y comprobables. Ejecuta las pruebas relacionadas e indica cuáles no pudiste ejecutar. Los motores, el hardware y las fuentes externas pueden no estar disponibles en todos los equipos.

Mantén los datos de usuario separados del código y los originales intactos. Las descargas de modelos y el uso de Internet deben ser visibles para el usuario. No agregues telemetría, servicios públicos ni transmisión de documentos sin una decisión explícita del proyecto.

Conserva las atribuciones y aporta la licencia de cualquier dependencia o recurso nuevo. Las contribuciones al código propio se reciben bajo la licencia MIT del proyecto.
