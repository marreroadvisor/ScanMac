# Seguridad y privacidad

No incluyas contraseñas, documentos, bases de datos ni tokens en issues públicos. Para un defecto de seguridad, utiliza el aviso privado de vulnerabilidades de GitHub si está habilitado; evita publicar detalles explotables o datos sensibles.

Esta es una versión experimental, con firma local y sin notarización. El servidor opcional está pensado para uso privado en loopback; no lo expongas a Internet sin revisar su documentación y sus límites. Los informes de IA/alteraciones no son certificados.

El repositorio debe contener solo código, gráficos propios, documentación, licencias y pruebas sintéticas. Los modelos, la biblioteca y las credenciales se guardan fuera de él.
